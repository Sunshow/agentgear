## 功能命名：Gateways（网关）

## 配置文件设计

```yaml
# 移除原有的 upstream 配置，改为 gateways
gateways:
  - name: "anthropic"
    path: "/v1"                              # 匹配 /v1/* 的请求
    upstream: "https://api.anthropic.com"
    timeout: 300
    enabled: true
    
  - name: "openai"
    path: "/openai"                          # 匹配 /openai/* 的请求
    upstream: "https://api.openai.com"
    timeout: 120
    enabled: true
    
  - name: "custom"
    path: "/custom"
    upstream: "https://custom.example.com"
    timeout: 60
    enabled: false
```

## 转换器关联设计

转换器通过 `gateways` 字段指定应用到哪些网关：

```yaml
transformers:
  response:
    - name: "create_documents_to_ExitSpecMode"
      enabled: true
      tags: ["droid"]
      gateways: ["anthropic", "custom"]      # 可选：指定应用的网关，未配置则对所有网关生效
      source_tool: "create_documents"
      target_tool: "ExitSpecMode"
      accumulate: true
      param_mapping:
        - from: "new_documents[0].content"
          to: "plan"
```

**匹配规则：**
- `gateways` 未配置或为空 → 对所有网关生效
- `gateways` 已配置 → 仅对指定网关生效
- `tags` 和 `gateways` 条件同时满足才应用转换器

## 代码改动

### 1. 配置结构 (`internal/config/config.go`)
```go
type GatewayConfig struct {
    Name     string `mapstructure:"name"`
    Path     string `mapstructure:"path"`
    Upstream string `mapstructure:"upstream"`
    Timeout  int    `mapstructure:"timeout"`
    Enabled  bool   `mapstructure:"enabled"`
}

type Config struct {
    Server       ServerConfig       `mapstructure:"server"`
    Gateways     []GatewayConfig    `mapstructure:"gateways"`    // 替换 Upstream
    Logging      LoggingConfig      `mapstructure:"logging"`
    // ...
}
```

### 2. 路由注册 (`cmd/agentgear/main.go`)
- 遍历 `gateways` 配置，为每个启用的网关创建独立的 Handler
- 动态注册路由：`r.Any(gateway.Path+"/*path", handler.ProxyRequest)`

### 3. Handler 改造 (`internal/proxy/handler.go`)
- Handler 增加 `gatewayName` 字段
- 请求上下文传递当前网关名称
- 转换器匹配时检查 `gateways` 字段

### 4. 转换器配置 (`internal/transformer/`)
- `TransformerConfig` 增加 `Gateways []string` 字段
- 匹配逻辑：`len(gateways) == 0` 或 `contains(gateways, currentGateway)`

## GUI 界面设计

在侧边栏增加 **Gateways** 菜单项，页面包含：

1. **网关列表**：显示所有配置的网关，支持启用/禁用开关
2. **网关编辑**：
   - Name（唯一标识）
   - Path（路径前缀，如 `/v1`）
   - Upstream URL
   - Timeout
   - Enabled 开关
3. **新增/删除网关**

## API 接口

```
GET    /api/gateways              # 获取网关列表
POST   /api/gateways              # 创建网关
PUT    /api/gateways/:name        # 更新网关
DELETE /api/gateways/:name        # 删除网关
```
