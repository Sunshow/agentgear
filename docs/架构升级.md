## 项目升级概述

将 AgentGear 从纯 CLI 代理升级为 CLI + 跨平台 GUI 混合应用。CLI 和 GUI 独立部署，CLI 可单独容器化运行。

## 部署模式

### 模式 1: 服务器部署 (仅 CLI)

```bash
# 构建
cd proxy && go build -o agentgear ./cmd/agentgear

# Docker 部署
docker build -t agentgear:latest ./proxy
docker run -d -p 9000:9000 -p 9001:9001 -v ./config.yaml:/app/config.yaml agentgear:latest
```

### 模式 2: 桌面使用 (GUI + 内嵌 CLI)

GUI 启动时自动管理 CLI 进程，或连接远程 CLI 服务。

```
┌─────────────────────────────────────────────────┐
│  GUI (Tauri)                                    │
│  ┌───────────────────────────────────────────┐  │
│  │  可选: 内嵌 CLI 进程 或 连接远程 CLI      │  │
│  └───────────────────────────────────────────┘  │
└─────────────────────────────────────────────────┘
         │                           │
         ▼                           ▼
   本地 CLI 进程              远程 CLI 服务
   localhost:9001             server:9001
```

## 核心功能模块

### 1. 内存连接管理

```go
// proxy/internal/memory/store.go
type ConnectionStore struct {
    connections *RingBuffer[*ConnectionInfo]
    maxSize     int
    mu          sync.RWMutex
}

type StoreConfig struct {
    MaxConnections    int  `mapstructure:"max_connections"`    // 默认 1000
    MaxRequestBodyKB  int  `mapstructure:"max_request_body"`   // 默认 512
    MaxResponseBodyKB int  `mapstructure:"max_response_body"`  // 默认 512
    RetentionMinutes  int  `mapstructure:"retention_minutes"`  // 默认 60
}
```

### 2. Tagging 标签系统

```yaml
tagging:
  rules:
    - name: "droid-agent"
      priority: 100
      matchers:
        - type: "header"
          key: "User-Agent"
          pattern: ".*Droid.*"
      tags: ["droid"]

    - name: "cursor-agent"
      priority: 90
      matchers:
        - type: "header"
          key: "User-Agent"
          pattern: ".*Cursor.*"
      tags: ["cursor"]

    - name: "spec-mode"
      priority: 80
      matchers:
        - type: "body_json"
          path: "messages[*].content[*].text"
          pattern: ".*Spec mode is active.*"
      tags: ["spec-mode"]
```

**匹配器类型:** `header` | `body_json` | `query` | `path`

### 3. 转换器配置 (Tag 绑定)

```yaml
transformers:
  response:
    - name: "create_documents_to_ExitSpecMode"
      enabled: true
      tags: ["droid"]
      source_tool: "create_documents"
      target_tool: "ExitSpecMode"
      accumulate: true
      param_mapping:
        - from: "new_documents[0].content"
          to: "plan"

    - name: "Edit_params_cursor"
      enabled: true
      tags: ["cursor"]
      source_tool: "Edit"
      target_tool: "Edit"
      param_mapping:
        - from: "oldText"
          to: "old_str"

  request:
    - name: "ExitSpecMode_to_create_documents"
      enabled: true
      tags: ["droid"]
      source_tool: "ExitSpecMode"
      target_tool: "create_documents"
```

### 4. 内部 API (CLI 提供)

```
GET  /api/connections?limit=100&tags=droid&status=completed
GET  /api/connections/:id
DELETE /api/connections

GET  /api/tags
GET  /api/transformers
PUT  /api/transformers/:name

GET  /api/tagging/rules
PUT  /api/tagging/rules/:name
POST /api/tagging/test

GET  /api/stats
WS   /api/ws
```

### 5. GUI 主要视图

| 视图 | 功能 |
|-----|------|
| **连接设置** | 配置连接本地/远程 CLI 服务地址 |
| **连接列表** | 显示内存中的连接、按 Tag 过滤、实时更新 |
| **请求检查器** | 查看请求详情、显示匹配的 Tags、高亮工具定义 |
| **响应检查器** | 查看响应详情、显示工具调用、对比转换前后 |
| **转换器管理** | 按 Tag 分组显示、启用/禁用 |
| **标签规则管理** | 配置 tagging rules、测试匹配 |

2. 实现内存连接存储
