## 设计方案：模板化转换器

### 核心思路

将模板作为一种特殊的 TransformerDef，通过 `is_template` 标识。模板定义参数占位符，用户基于模板创建实例时填入具体值。

### 1. 数据结构扩展

```go
// TransformerDef 扩展
type TransformerDef struct {
    Name         string         
    Description  string         
    Direction    string         
    SourceTool   string         // 模板中可用占位符如 "{{source}}"
    TargetTool   string         // 模板中可用占位符如 "{{target}}"
    Accumulate   bool           
    ParamMapping []ParamMapping 
    Builtin      bool           
    
    // 模板相关字段
    IsTemplate   bool                    `json:"is_template,omitempty"`   // 是否为模板
    TemplateRef  string                  `json:"template_ref,omitempty"`  // 引用的模板名称
    TemplateArgs map[string]string       `json:"template_args,omitempty"` // 模板参数值
}
```

### 2. 内置模板定义


### 5. 模板解析逻辑

在 Registry 中添加模板解析：

```go
func (r *Registry) resolveTemplate(def *TransformerDef) *TransformerDef {
    if def.TemplateRef == "" {
        return def
    }
    
    // 查找模板
    var tpl *TransformerDef
    for i := range r.definitions {
        if r.definitions[i].Name == def.TemplateRef && r.definitions[i].IsTemplate {
            tpl = &r.definitions[i]
            break
        }
    }
    if tpl == nil {
        return def
    }
    
    // 替换占位符
    resolved := *def
    resolved.Direction = replacePlaceholder(tpl.Direction, def.TemplateArgs)
    resolved.SourceTool = replacePlaceholder(tpl.SourceTool, def.TemplateArgs)
    resolved.TargetTool = replacePlaceholder(tpl.TargetTool, def.TemplateArgs)
    resolved.TemplateRef = ""
    
    return &resolved
}

func replacePlaceholder(s string, args map[string]string) string {
    for k, v := range args {
        s = strings.ReplaceAll(s, "{{"+k+"}}", v)
    }
    return s
}
```
